# Extended allocation and geometry evaluation

The [protocol](protocol.md) was recorded before the grid execution on 14 September 2026, after these eight source scenes had already informed development. Grouped scene reuse is exploratory; it is not an untouched external test or preregistration.

From the repository root, with the documented NumPy dependencies:

```sh
python scripts/extended_study.py
python scripts/geometry_stress.py
python scripts/check_extended.py
```

For measured renderer occupancy, also install `requirements-render.txt` and run `python scripts/occupancy_study.py`. The narrow video sample is generated by `python scripts/video_audit.py --sheets work/video_audit`; obtain the source clip with the downloader in `demos/real_driving` first. The annotations are a machine-assisted visual audit, not generated human ground truth. Running the sample generator does not revalidate annotations.

| Artifact | Contents |
|---|---|
| `summary.json` | Default results, grouped configuration-selection outcomes and descriptive intervals |
| `grid.json` | 360 configurations, each evaluated on 32 sequences |
| `folds.json` | All 128 selected family/preference/fold combinations and held-scene rows |
| `default_sequences.json`, `default_traces.json` | Five policy families, sequence metrics and per-frame decisions |
| `sensitivity.json` | Eight factorial combinations and 16 one-factor settings |
| `geometry_summary.json`, `geometry_rows.jsonl.gz` | Analytic geometry perturbations, conditional errors and availability |
| `occupancy_summary.json`, `occupancy_frames.json` | Native-resolution nonzero rendered pixel support, excluding panels |
| `video_audit_sample.json`, `video_audit_annotations.json` | Fixed one-second sampling and narrow ego-vehicle-region audit |

Risk-threshold, risk-hysteresis and risk-dwell selectors are independently implemented in `prism/study.py`. They share candidate states, detail rules, quality gate, overlap and capacities with PRISM. Simple dwell ranking matches default PRISM's clear-scene reference coverage and mean count, with fewer transitions. PRISM has slightly less painted support. No consistent dominance is established.

The reference is the largest heuristic priority on generative states, not independently labelled driving relevance. Painted support is not perceived clutter. A reference bout is not a collision event. Seven source scenes have eligible references; bootstrap intervals are conditional, exploratory, and unadjusted for multiple comparisons. Noiseless analytic replicates are repeated identical trajectories, not independent evidence. TTC errors are conditional on finite estimates. These data do not establish road-hazard accuracy, driver benefit or capture-to-display real-time deployment.
